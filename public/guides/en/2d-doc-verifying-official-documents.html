2D-Doc: the only check that proves something

Updated 11 November 2026

Every check described in the other guides is circumstantial — it makes fraud more or less likely, never certain. 2D-Doc is different: it rests on cryptography, and allows a clear-cut answer.

In short

  • 2D-Doc is a DataMatrix barcode defined by the French ANTS, printed on tax notices, pay slips and official certificates, that carries the document's key data and their signature.
  • If the data in the code differs from the printed text, the visible document has been edited.
  • A valid signature proves the data in the code was issued by the signing organisation and has not been altered; it does not cover the rest of the page.
  • TrustyFile decodes the 2D-Doc and verifies its signature offline, with the certificates published by ANTS.

What a 2D-Doc is

2D-Doc is a two-dimensional DataMatrix barcode specified by the French ANTS (national agency for secure documents). It appears on tax notices, pay slips, social security certificates, proof-of-address bills from some suppliers, and assorted administrative documents.

It holds two things: the document's key data in clear text (name, amount, date, reference), and a cryptographic signature of that data, produced with the issuer's private key.

Why it beats everything else

Metadata can be rewritten, fonts can be imitated, a scan erases the traces. A cryptographic signature cannot: without the issuer's private key you cannot produce a valid signature over modified data.

That yields two distinct checks, and the difference between them matters:

  • Is the code readable and consistent? Does the encoded data match the text printed on the document? If the PDF shows one amount and the code holds another, somebody edited the visual without being able to touch the code.
  • Is the signature valid? This requires the issuer's certificate and an ECDSA verification. It is the only check that can assert a document is genuine, rather than merely "no anomaly detected".

Where TrustyFile stands

TrustyFile runs both checks. It decodes the 2D-Doc and compares the encoded data against the visible text, which catches visual edits. It then verifies the ECDSA signature, offline, with the certificates published by ANTS.

A valid signature proves one precise thing: the data held in the code was issued by the signing organisation and has not been altered. It says nothing about the parts of the page the code does not carry, nor about who is sending you the document. And when the issuer's certificate cannot be found, or the code cannot be read, TrustyFile says so rather than conclude.

Check with the issuer in parallel

For a French tax notice, the tax administration runs an online verification service (SVAIR) where you enter the tax number and the notice reference. The answer comes from the source itself, which beats any file analysis.

General rule: when the issuer offers a way to verify directly with them, that is always the route to take first.

Frequently asked questions

How do I verify a 2D-Doc barcode?
Decode it, compare its data with the printed text, then verify its signature against the issuer's certificate. TrustyFile runs all three steps on an uploaded PDF or on a photo of the code.
Does a valid 2D-Doc prove the document is genuine?
It proves the data held in the code is genuine. It says nothing about information the code does not carry, nor about who is presenting the document.
What if a document has no 2D-Doc?
Nothing can be concluded. Many issuers do not print one. The other checks on the file, and checking with the issuer, remain the reference.
