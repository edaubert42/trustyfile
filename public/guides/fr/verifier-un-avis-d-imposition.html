Comment vérifier un avis d'imposition

Mis à jour le 11 novembre 2026

L'avis d'impôt sur le revenu est la pièce maîtresse d'un dossier de location et de nombreuses demandes d'aide ou de crédit : il fixe le revenu fiscal de référence du foyer. C'est aussi le justificatif le plus retouché des dossiers locatifs, parce qu'un revenu gonflé ouvre des portes que le vrai revenu ferme. Il se vérifie pourtant mieux que presque tout autre document : l'administration fiscale met à disposition un service de contrôle en ligne, et l'avis porte un code 2D-Doc signé.

En bref

  • Un avis d'imposition se vérifie sur le service officiel SVAIR (impots.gouv.fr) avec le numéro fiscal et la référence de l'avis.
  • SVAIR confirme que l'avis existe et qu'il est le dernier émis, mais n'affiche aucun montant : un revenu gonflé sur un avis authentique passe ce contrôle.
  • Le code 2D-Doc signé de l'avis contient le revenu fiscal de référence : s'il diffère du montant imprimé, l'avis a été retouché.
  • Recoupez l'avis avec les bulletins de salaire, le justificatif de domicile et la situation de famille annoncée.

Ce que dit un avis, et ce qui se falsifie

L'avis indique le numéro fiscal du déclarant (13 chiffres), la référence de l'avis (13 chiffres), le revenu fiscal de référence, le nombre de parts, le montant de l'impôt, l'adresse et la situation de famille. Il porte deux années : celle des revenus déclarés et celle de l'émission, qui la suit. Juste après la déclaration, l'« avis de situation déclarative » (ASDIR) en tient lieu, avec les mêmes identifiants.

Les fraudes suivent quatre schémas : un revenu fiscal de référence gonflé sur un avis authentique ; un vieil avis dont on a changé l'année ; l'avis d'une autre personne dont on a remplacé le nom et l'adresse ; un document entièrement fabriqué à partir d'un modèle. Les deux premiers sont les plus courants, et les deux contrôles ci-dessous, pris ensemble, les attrapent tous : le premier établit que l'avis existe et qu'il est le dernier émis, le second que ses chiffres n'ont pas été touchés.

Le service de vérification des avis (SVAIR)

La Direction générale des Finances publiques propose un service de vérification des avis (SVAIR), accessible sans compte depuis impots.gouv.fr, rubrique « Vérifier un avis d'impôt », et destiné précisément aux tiers à qui l'avis est présenté : bailleurs, agences, administrations. Saisissez les deux identifiants imprimés sur le document — le numéro fiscal (13 chiffres) et la référence de l'avis (13 chiffres) — et le service répond d'un mot : conforme si ce couple correspond au dernier avis connu de l'administration pour cet usager, non conforme sinon. Il n'affiche aucun montant : la confidentialité des données fiscales l'interdit.

Lisez ce verdict pour ce qu'il est. « Non conforme » signifie que le couple est inconnu — document fabriqué, identifiant retouché ou mal saisi — ou qu'un avis plus récent a été émis depuis : le candidat montre un ancien avis, peut-être remplacé par une déclaration rectificative. « Conforme » prouve qu'un avis authentique porte bien ces identifiants et qu'il est le dernier en date ; il ne prouve pas que les chiffres imprimés sont ceux d'origine, puisque le service ne les compare pas. Un revenu gonflé sur un avis authentique et à jour passe ce contrôle : c'est le code 2D-Doc qui l'attrape.

Le code 2D-Doc

Les avis portent un code 2D-Doc : un DataMatrix signé électroniquement par l'administration fiscale, qui reprend les données clés du document (revenu fiscal de référence, nombre de parts, référence de l'avis, numéro fiscal, année). Un lecteur 2D-Doc le décode et vérifie la signature ; TrustyFile le fait pour tout PDF déposé, hors ligne, avec les certificats publiés par l'autorité.

Si les données décodées diffèrent de celles imprimées, le texte visible a été retouché et le code, lui, dit la vérité. Si la signature est invalide, le code a été recomposé — ce qu'un faussaire ne peut pas faire correctement sans la clé privée de l'administration. Un code illisible (scan flou, photo) n'est en revanche pas une preuve : il vous laisse avec le contrôle SVAIR — qui atteste l'existence de l'avis, pas ses chiffres — et les recoupements ci-dessous. Le guide sur le 2D-Doc détaille le mécanisme.

Les recoupements avec le reste du dossier

Un avis cohérent avec lui-même peut ne pas l'être avec le dossier :

  • Bulletins de salaire : pour un salarié sans autre revenu, le revenu fiscal de référence est proche du cumul annuel « net imposable » des bulletins, diminué de l'abattement de 10 % pour frais professionnels ; certains revenus exonérés y sont réintégrés et peuvent creuser l'écart. Un écart de plusieurs milliers d'euros demande une explication (autres revenus, changement de situation). Voir le guide sur les bulletins de salaire.
  • Adresse : celle de l'avis doit correspondre au justificatif de domicile et à l'historique déclaré.
  • Nombre de parts : cohérent avec la situation de famille annoncée (une part pour une personne seule, deux pour un couple, puis les demi-parts pour les enfants à charge).
  • Années : un avis émis l'année N porte sur les revenus de N-1 ; un « dernier avis » de deux ans n'est pas le dernier.
  • Orthographe des noms et civilité identiques sur toutes les pièces.

Les indices dans le fichier PDF

Un avis téléchargé depuis l'espace particulier d'impots.gouv.fr est un PDF numérique natif, produit d'un bloc par la chaîne de l'administration. Un avis modifié dans un éditeur PDF garde des traces : une révision ajoutée après la création, une police légèrement différente sur le montant retouché, l'ancien chiffre encore présent sous un rectangle blanc, des métadonnées d'éditeur ou de convertisseur en ligne. Le guide sur les PDF modifiés passe ces indices en revue.

Un avis scanné ou photographié perd tout cela : ni structure PDF exploitable, ni code 2D-Doc souvent lisible. Ce n'est pas un signe de fraude — beaucoup de gens n'ont qu'une version papier — mais c'est un document non vérifiable par lui-même. Demandez le PDF d'origine : lui seul permet de lire le code 2D-Doc et de contrôler les montants.

Cadre légal et bons réflexes

Un bailleur peut demander à un candidat son dernier ou avant-dernier avis d'imposition ou de non-imposition : la pièce figure dans la liste limitative fixée par le décret du 5 novembre 2015, qui interdit d'exiger d'autres documents que ceux qu'il énumère. Présenter un avis falsifié relève du faux et de l'usage de faux (article 441-1 du code pénal, jusqu'à trois ans d'emprisonnement et 45 000 euros d'amende).

Face à un avis douteux : ne concluez pas, conservez le document et les échanges, et gardez à l'esprit que les pièces d'un candidat non retenu ne doivent pas être conservées au-delà du nécessaire. TrustyFile n'archive rien : le fichier est analysé, puis supprimé.

Questions fréquentes

Comment vérifier l'avis d'imposition d'un locataire ?
Saisissez le numéro fiscal et la référence de l'avis sur le service de vérification des avis (SVAIR) d'impots.gouv.fr, puis contrôlez le code 2D-Doc, qui atteste les montants. TrustyFile lit ce code et vérifie sa signature sur le PDF déposé.
Que signifie « non conforme » sur SVAIR ?
Que le couple numéro fiscal et référence est inconnu (document fabriqué, identifiant retouché ou mal saisi), ou qu'un avis plus récent a été émis depuis.
Un avis « conforme » sur SVAIR peut-il être falsifié ?
Oui : SVAIR ne compare pas les montants. Un revenu fiscal de référence gonflé sur un avis authentique et à jour passe ce contrôle ; c'est le code 2D-Doc qui l'attrape.
